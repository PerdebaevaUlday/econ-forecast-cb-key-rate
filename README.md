# Превысит ли ключевая ставка ЦБ РФ отметку в 16% на заседании 18.12.2026?

> Мой прогноз: 4% · ИИ: 5% · разрешится 18.12.2026 · автор <ПердебаеваУлдай>

## 2. Прогноз

Вероятность исхода «да»: **4%**.

| Состояние | Вероятность |
| :--- | :--- |
| Ставка будет > 16% | 4% |
| Ставка будет ≤ 16% | 96% |

Наиболее вероятным сценарием считаю сохранение ключевой ставки на текущем уровне 14% или её снижение. Текущий уровень инфляции и прогнозы регулятора не создают предпосылок для столь резкого ужесточения политики.

## 3. Обоснование

1. **Текущий уровень ставки — 14%.** На заседании 23.10.2026 ЦБ сохранил ставку на этом уровне. Для превышения 18% потребовался бы скачок более чем на 400 б.п., что рынком не закладывается. — [Банк России](https://www.cbr.ru/hd_base/keyrate/).
2. **Базовый прогноз ЦБ не предполагает роста.** Регулятор повысил прогноз *средней* ставки на 2027 год до 12,5–13,5%, что ниже текущих 14%. — [Банк России: прогноз](https://www.cbr.ru/dkp/mp_dec/decision_key_rate/comment_05112026/).
3. **Консенсус аналитиков.** «Финам» ожидает сохранения 14% 18 декабря, «Велес Капитал» — 14% в начале 2027 года. Повышение до 18% не обсуждается. — [Финам](https://www.finam.ru/).
4. **Рыночные вероятности.** На Kalshi вероятность повышения ставки более чем на 25 б.п. оценивается всего в 4%. Для скачка до 16% нет никаких рыночных предпосылок. — [Kalshi](https://kalshi.com/markets/kxrate).
5. **Инфляционное давление.** Хотя инфляция остаётся повышенной (прогноз 7,1–7,6%), ЦБ борется с ней удержанием ставки на высоком уровне, а не экстренным повышением. — [Банк России: инфляция](https://www.cbr.ru/statistics/macro_itm/inflation/).
